# FAST-EQA agent Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `--agent drones.fasteqa:make` answers the EQA benchmarks the way FAST-EQA (arXiv 2602.15813) does, with its reasoner, scorer, image-text embedder and depth source each swappable from `--agent-arg`.

**Architecture:** A new package `src/drones/fasteqa/` holds a plain agent object that the existing `drones-render-agent` and `drones-benchmark` run unchanged. Pure-numpy modules (`mapping`, `memory`, `prompts`) carry the algorithm and are tested without the simulator; `embedder` and `depth` wrap transformers models, imported inside functions. Two small backward-compatible additions outside the package: oracle depth from `LensCamera`/`SceneView`/`agents.episode`, and several images plus `yes_probability` in `drones.vlm.backend`.

**Tech Stack:** Python 3, numpy, MuJoCo (oracle depth), the existing `drones.vlm.backend` backends, transformers + torch (`vlm` extra) for SigLIP/CLIP/Depth Anything, pytest.

**Spec:** `docs/superpowers/specs/2026-10-07-fasteqa-design.md`

## Review Focus

1. **A question with no plausible room, or a parse reply that never validates** → the agent explores by frontiers alone and still answers; pinned in Task 6 (`test_a_parse_that_never_validates_falls_back_to_the_question`).
2. **Start pose next to a wall, so the drone's own cell is inside the inflated obstacle band** → A* still starts; pinned in Task 3 (`test_astar_starts_inside_the_inflation`).
3. **A frame whose depth is all `inf` (looking at open space or sky through a window)** → carved free to `MAX_DEPTH`, never occupied, no NaN; pinned in Task 3 (`test_misses_carve_free_space_without_occupying`).
4. **No reachable frontier left (everything explored, or the map is tiny)** → the agent turns in place, never raises, and the budget's `conclude` answers; pinned in Task 6 (`test_with_nowhere_to_go_it_turns_in_place`).
5. **An `openai` scorer whose server returns no `logprobs`** (a server started without them) → the scorer falls back to the yes/no reply rather than crashing; pinned in Task 2 (`test_yes_probability_without_logprobs_reads_the_reply`).

```python
def episode(view, agent, start, question=None, max_steps=MAX_STEPS):
    """Run `agent` in a SceneView from Pose `start`: yields each Observation it is shown, the
    start's included, until it stops or has taken `max_steps` steps. The drone in `view` is at
    the observation's pose while it is handled, for other cameras to film."""
    if hasattr(agent, 'camera') and hasattr(view, 'lens'):
        agent.camera = CameraInfo(view.lens.intrinsics, view.mount)
    wants_depth = bool(getattr(agent, 'depth', False))
    agent.reset(question, start)
    pose = start
    for step in range(max_steps + 1):
        depth = None
        if wants_depth:
            image, depth = view.render_matrix(pose.pos, pose.rotation, depth=True)
        else:
            image = view.render_matrix(pose.pos, pose.rotation)
        observation = Observation(image, pose, step, question, depth)
        yield observation
        if step == max_steps:
            return
        pose = agent.act(observation)
        if pose is None:
            return
        pose = Pose(np.asarray(pose.pos, float), float(pose.yaw), float(pose.pitch),
                    float(pose.roll))
```

- [ ] **Step 7: Implement oracle depth** in `src/drones/sim/lens.py`. Add to the module docstring's "Why" list:

```
- Depth is read from MuJoCo's depth buffer by `mujoco.Renderer`, which linearises it with the
  model's own near plane (`vis.map.znear` × extent), not the frustum's: `render` overwrites the
  frustum's near plane, so the model's is set to match for the read and put back. Without that,
  every depth is wrong by a factor that depends on the scene's size. Depth is looked up through
  the lens with the nearest tap and the nearest of the supersamples, never blended: a blend across
  an edge is a point in mid-air.
```

```python
    def _depth(self, near):
        """The depth buffer of the scene just rendered, through the lens (see the docstring)."""
        vis = self.model.vis.map
        extent = self.model.stat.extent
        far = vis.zfar * extent
        znear = vis.znear
        vis.znear = near / extent
        self._renderer.enable_depth_rendering()
        try:
            buffer = self._renderer.render()
        finally:
            self._renderer.disable_depth_rendering()
            vis.znear = znear
        z = buffer[self._nearest].astype(np.float32)
        z[z >= 0.999 * far] = np.inf
        s = self._supersample
        return z.reshape(self.height, s, self.width, s).min(axis=(1, 3))
```

```python
YES, NO = 'yes', 'no'
TOP_LOGPROBS = 20       # alternatives vLLM returns for the first token


def images(image):
    """`image` as a list: None is none, one (height, width, 3) array is one."""
    if image is None:
        return []
    if isinstance(image, np.ndarray):
        return [image]
    return list(image)


def yes_share(pairs):
    """P(yes) / (P(yes) + P(no)) over (token, logprob) `pairs`, every spelling of each word
    summed; None when neither word is among them."""
    totals = {YES: 0.0, NO: 0.0}
    for token, logprob in pairs:
        word = token.strip().lower()
        if word in totals:
            totals[word] += float(np.exp(logprob))
    both = totals[YES] + totals[NO]
    return totals[YES] / both if both > 0 else None


def yes_from_logits(logits, tokenizer):
    """yes_share of the next token from its `logits` (numpy), over the first token of each
    spelling of yes and no. A spelling's tokens are counted once, whichever spellings share it."""
    logits = np.asarray(logits, np.float64)
    logp = logits - logits.max()
    logp = logp - np.log(np.exp(logp).sum())
    pairs, seen = [], set()
    for word in (YES, NO):
        for spelling in (word, word.capitalize(), ' ' + word, ' ' + word.capitalize()):
            token = tokenizer.encode(spelling, add_special_tokens=False)[0]
            if token not in seen:
                seen.add(token)
                pairs.append((word, logp[token]))
    return yes_share(pairs)
```

`src/drones/fasteqa/mapping.py`:

```python
"""FAST-EQA's map: what the drone has seen, as a floor plan, and where to go next.

The paper fuses RGB-D into a TSDF and works on a 2D slice of its occupancy; this keeps only the
slice. Each depth pixel is a ray from the eye: the cells it crosses are free, and the cell it ends
in is occupied if the hit is between BAND[0] and BAND[1] above the floor (a wall, a sofa), not if
it is the floor or the ceiling. A ray that hits nothing within MAX_DEPTH carves free space to
MAX_DEPTH and occupies nothing, so open space is mapped as open. Occupied cells are never freed
again: an oracle's depth has no noise to undo, and an estimator's errors are better kept as
obstacles than flown through.

Doorways are the paper's Eq. 1, widened to a door: a free cell with occupied cells within
DOOR_HALF on both sides along x, or along y. That also marks narrow passages between furniture,
as the paper's test does. Frontiers are free cells beside unknown ones. Both are clustered with
DBSCAN on the grid (cells within `radius` cells are neighbours), and the drone is flown to one
along an A* path over free cells kept INFLATE from anything occupied, so it never crosses what
it has seen. Nothing collides with the scan, so a plan through unknown space would be flown
through walls; A* never enters unknown cells.

numpy and the stdlib only: the map is tested without the simulator.
"""
import heapq
import math

import numpy as np

CELL = 0.1              # m per grid cell
BAND = (0.1, 2.0)       # m above the floor that count as obstacles
MAX_DEPTH = 5.0         # m; depth beyond this carves free space and occupies nothing
EXTENT = 40.0           # m on a side, centred on the start: an HM3D house fits
INFLATE = 0.2           # m kept from occupied cells when planning
DOOR_HALF = 0.6         # m: an occupied cell this close on both sides makes an opening
EPS = 0.3               # m: DBSCAN's neighbourhood
MIN_POINTS = 4          # DBSCAN's core size, the cell itself included
BLOCKED_COST = 10.0     # times the cost of crossing a free cell inside the inflation band
UNKNOWN, FREE, OCCUPIED = 0, 1, 2


def backproject(depth, intrinsics, eye, rotation, stride=1, max_depth=MAX_DEPTH):
    """World points of a z-depth image: (hits, misses). A miss is a pixel with no depth within
    `max_depth`, put at `max_depth` along its ray. Every `stride`-th pixel along each axis."""
    depth = np.asarray(depth, np.float32)[::stride, ::stride]
    h, w = depth.shape
    v, u = np.mgrid[0:h, 0:w]
    u, v = u * stride, v * stride
    x, y = intrinsics.undistort((u - intrinsics.cx) / intrinsics.fx,
                                (v - intrinsics.cy) / intrinsics.fy)
    # Camera axes forward, left, up: pixel (x right, y down) at depth d is (d, -x d, -y d).
    rays = np.stack([np.ones_like(x), -x, -y], axis=-1).reshape(-1, 3) @ np.asarray(rotation).T
    d = depth.reshape(-1)
    hit = np.isfinite(d) & (d > 0) & (d <= max_depth)
    eye = np.asarray(eye, float)
    hits = eye + rays[hit] * d[hit, None]
    # NaN (an estimator's hole) is neither: it says nothing about the space along its ray.
    miss = (d > max_depth) & ~np.isnan(d)
    # A miss reaches max_depth along the ray, not max_depth of z-depth.
    lengths = np.linalg.norm(rays[miss], axis=1)
    misses = eye + rays[miss] * (max_depth / lengths)[:, None]
    return hits, misses


class OccupancyMap:
    """A floor plan `extent` m square around `center` (x, y), in `cell` m cells, of a floor at
    height `floor`. `grid[ix, iy]` is UNKNOWN, FREE or OCCUPIED."""

    def __init__(self, center, floor, cell=CELL, extent=EXTENT, band=BAND):
        self.cell, self.floor, self.band = float(cell), float(floor), band
        n = int(round(extent / cell))
        self.grid = np.zeros((n, n), np.uint8)
        self.origin = np.asarray(center, float)[:2] - n * self.cell / 2

    def index(self, xy):
        """(N, 2) int cells of (N, 2) points, clipped to the grid."""
        cells = np.floor((np.asarray(xy, float).reshape(-1, 2) - self.origin) / self.cell)
        return np.clip(cells, 0, len(self.grid) - 1).astype(np.intp)

    def centre(self, cells):
        """(N, 2) points at the centres of `cells`."""
        return self.origin + (np.asarray(cells, float).reshape(-1, 2) + 0.5) * self.cell

    def fuse(self, eye, hits, misses):
        """Add the rays from `eye` to each of `hits` (which may occupy) and `misses` (which do
        not)."""
        hits = np.asarray(hits, float).reshape(-1, 3)
        ends = np.concatenate([hits, np.asarray(misses, float).reshape(-1, 3)])
        if not len(ends):
            return
        start = np.asarray(eye, float)[:2]
        span = ends[:, :2] - start
        length = np.linalg.norm(span, axis=1)
        steps = max(1, int(math.ceil(length.max() / (self.cell / 2))))
        t = np.arange(steps) / steps                       # the end itself is left out
        points = start + span[:, None, :] * t[None, :, None]
        free = self.index(points.reshape(-1, 2))
        free_mask = self.grid[free[:, 0], free[:, 1]] != OCCUPIED
        self.grid[free[free_mask, 0], free[free_mask, 1]] = FREE
        above = hits[:, 2] - self.floor
        solid = hits[(above > self.band[0]) & (above < self.band[1])]
        if len(solid):
            cells = self.index(solid[:, :2])
            self.grid[cells[:, 0], cells[:, 1]] = OCCUPIED

    def _within(self, mask, reach, axis, sign):
        """Cells with a `mask` cell 1..`reach` cells away along `axis` in direction `sign`."""
        out = np.zeros_like(mask)
        n = mask.shape[axis]
        for k in range(1, reach + 1):
            if sign > 0:
                src = [slice(None)] * 2
                dst = [slice(None)] * 2
                src[axis], dst[axis] = slice(k, n), slice(0, n - k)
            else:
                src = [slice(None)] * 2
                dst = [slice(None)] * 2
                src[axis], dst[axis] = slice(0, n - k), slice(k, n)
            out[tuple(dst)] |= mask[tuple(src)]
        return out

    def doorways(self):
        """Free cells with occupied ones within DOOR_HALF on both sides along x, or along y."""
        occupied = self.grid == OCCUPIED
        reach = max(1, int(round(DOOR_HALF / self.cell)))
        pinched = np.zeros_like(occupied)
        for axis in (0, 1):
            pinched |= (self._within(occupied, reach, axis, 1)
                        & self._within(occupied, reach, axis, -1))
        return (self.grid == FREE) & pinched

    def frontiers(self):
        """Free cells with an unknown 4-neighbour."""
        unknown = self.grid == UNKNOWN
        near = np.zeros_like(unknown)
        near[1:, :] |= unknown[:-1, :]
        near[:-1, :] |= unknown[1:, :]
        near[:, 1:] |= unknown[:, :-1]
        near[:, :-1] |= unknown[:, 1:]
        return (self.grid == FREE) & near

    def traversable(self, inflate=INFLATE):
        """Free cells at least `inflate` m from every occupied cell."""
        occupied = self.grid == OCCUPIED
        r = int(math.ceil(inflate / self.cell))
        blocked = occupied.copy()
        for axis in (0, 1):
            blocked |= self._within(occupied, r, axis, 1) | self._within(occupied, r, axis, -1)
        # Diagonals too: dilate the row-dilated mask along columns.
        rows = occupied.copy()
        rows |= self._within(occupied, r, 0, 1) | self._within(occupied, r, 0, -1)
        blocked |= self._within(rows, r, 1, 1) | self._within(rows, r, 1, -1)
        return (self.grid == FREE) & ~blocked

    def unknown_near(self, cell, radius):
        """The fraction of cells within `radius` m of `cell` that are unknown."""
        r = int(math.ceil(radius / self.cell))
        ix, iy = cell
        patch = self.grid[max(0, ix - r):ix + r + 1, max(0, iy - r):iy + r + 1]
        return float((patch == UNKNOWN).mean()) if patch.size else 0.0


def clusters(mask, radius, min_points):
    """DBSCAN over the True cells of `mask`, neighbours being within `radius` cells along both
    axes: a list of (k, 2) cell arrays, noise left out."""
    cells = [tuple(c) for c in np.argwhere(mask)]
    present = set(cells)
    offsets = [(dx, dy) for dx in range(-radius, radius + 1) for dy in range(-radius, radius + 1)]

    def neighbours(c):
        return [(c[0] + dx, c[1] + dy) for dx, dy in offsets if (c[0] + dx, c[1] + dy) in present]

    core = {c for c in cells if len(neighbours(c)) >= min_points}
    label, found = {}, []
    for seed in cells:
        if seed not in core or seed in label:
            continue
        group, queue = [], [seed]
        label[seed] = len(found)
        while queue:
            c = queue.pop()
            group.append(c)
            if c not in core:
                continue                    # a border cell joins but does not extend
            for n in neighbours(c):
                if n not in label:
                    label[n] = len(found)
                    queue.append(n)
        found.append(np.array(group, np.intp))
    return found


def astar(passable, start, goal, free=None):
    """The cheapest 8-connected path of cells from `start` to `goal` over `passable` cells, both
    ends included, or None. Cells that are `free` but not passable (inside the inflation band)
    cost BLOCKED_COST times as much: a drone that starts beside a wall must be able to leave it,
    and a path still keeps off walls wherever it can. `start` may be anything: the drone is where
    it is."""
    start, goal = tuple(int(v) for v in start), tuple(int(v) for v in goal)
    if not passable[goal]:
        return None
    n, m = passable.shape
    steps = [(dx, dy, math.hypot(dx, dy)) for dx in (-1, 0, 1) for dy in (-1, 0, 1)
             if dx or dy]
    best = {start: 0.0}
    came = {}
    frontier = [(math.dist(start, goal), 0.0, start)]
    while frontier:
        _, cost, c = heapq.heappop(frontier)
        if c == goal:
            path = [c]
            while c in came:
                c = came[c]
                path.append(c)
            return path[::-1]
        if cost > best.get(c, math.inf):
            continue
        for dx, dy, step in steps:
            nxt = (c[0] + dx, c[1] + dy)
            if not (0 <= nxt[0] < n and 0 <= nxt[1] < m):
                continue
            if passable[nxt]:
                new = cost + step
            elif free is not None and free[nxt]:
                new = cost + step * BLOCKED_COST
            else:
                continue
            if new < best.get(nxt, math.inf):
                best[nxt], came[nxt] = new, c
                heapq.heappush(frontier, (new + math.dist(nxt, goal), new, nxt))
    return None
```

```python
"""FAST-EQA's memory: for each target, the k views most relevant to it.

The paper's point is that memory grows with the number of targets, not with the episode: M
targets keep at most M × k images, which is what the stop check and the answer look at. A view
that is among the best for several targets is kept once.
"""
from dataclasses import dataclass

import numpy as np


@dataclass(frozen=True, eq=False)
class View:
    image: np.ndarray       # (height, width, 3) uint8
    pos: np.ndarray         # where the drone was
    yaw: float
    step: int


class Memory:
    def __init__(self, targets, k=3):
        self.k = int(k)
        self.kept = {t: [] for t in targets}       # target -> [(score, view)], best first
        self.changed = False

    def offer(self, view, scores):
        """Keep `view` for each target it is among the k best for; True if anything changed."""
        changed = False
        for target, score in scores.items():
            kept = self.kept[target]
            if len(kept) < self.k or score > kept[-1][0]:
                kept.append((float(score), view))
                kept.sort(key=lambda pair: -pair[0])
                del kept[self.k:]
                changed = True
        self.changed |= changed
        return changed

    def views(self):
        """Every kept view once, by its best score, best first."""
        best = {}
        for kept in self.kept.values():
            for score, view in kept:
                if id(view) not in best or score > best[id(view)][0]:
                    best[id(view)] = (score, view)
        return [view for _, view in sorted(best.values(), key=lambda pair: -pair[0])]

    def best(self):
        """The best score per target, 0 for a target with nothing kept."""
        return {t: (kept[0][0] if kept else 0.0) for t, kept in self.kept.items()}
```

```python
"""FAST-EQA's prompts, and how their replies are read.

The paper's own prompts are in a supplementary that was not available, so these are written
here, after its description: the question is parsed into visual targets and the rooms they are
likely in; a view's relevance to the question is a yes/no; the stop check and the answer look at
the memory's images and reason step by step before a last `Answer:` line. A reply that does not
give that line is a "keep exploring", whatever else it says.
"""
import json
import re

MAX_TARGETS = 4
# The room names a frame is tagged with, by the embedder, zero-shot. A parsed room outside this
# list is added to it for the question.
ROOMS = ('bedroom', 'bathroom', 'kitchen', 'living room', 'dining room', 'hallway', 'office',
         'laundry room', 'garage', 'closet', 'staircase', 'entrance')
REASONER_SYSTEM = ('You help an indoor drone answer a question about the house it flies in. '
                   'Follow the format the user asks for exactly.')
_ANSWER = re.compile(r'^\s*answer\s*:\s*(.+?)\s*$', re.IGNORECASE | re.MULTILINE)
_OBJECT = re.compile(r'\{.*\}', re.DOTALL)


def _question(question, choices):
    text = f'Question: {question}'
    if choices:
        text += '\nOptions:\n' + '\n'.join(choices)
    return text


def parse_prompt(question, choices=()):
    return (f'{_question(question, choices)}\n\n'
            'An indoor drone must look for the evidence to answer this question. List the '
            f'objects it should look for (at most {MAX_TARGETS}, most important first) and the '
            'rooms they are most likely in, as one JSON object and nothing else:\n'
            '{"targets": ["<object>", ...], "rooms": ["<room>", ...]}')


def parse_plan(reply):
    """(targets, rooms) from a parse reply, rooms in lower case; ValueError if it is not one."""
    found = _OBJECT.search(reply)
    if not found:
        raise ValueError(f'no JSON object in {reply[:200]!r}')
    try:
        plan = json.loads(found.group(0))
    except json.JSONDecodeError as exc:
        raise ValueError(f'not JSON: {exc}') from None
    targets, rooms = plan.get('targets'), plan.get('rooms', [])
    if not isinstance(targets, list) or not targets \
            or not all(isinstance(t, str) and t.strip() for t in targets):
        raise ValueError(f'targets must be a non-empty list of names, not {targets!r}')
    if not isinstance(rooms, list) or not all(isinstance(r, str) for r in rooms):
        raise ValueError(f'rooms must be a list of names, not {rooms!r}')
    return ([t.strip() for t in targets][:MAX_TARGETS],
            [r.strip().lower() for r in rooms if r.strip()])


def relevance_prompt(question):
    return (f'Question: {question}\n\nDoes this image show evidence that helps answer the '
            'question? Reply with one word, yes or no.')


def read_yes(reply):
    """1.0 if the reply's first word is yes, else 0.0."""
    words = reply.strip().lower().split()
    return 1.0 if words and words[0].strip('.,!') == 'yes' else 0.0


def stop_prompt(question, choices, count):
    return (f'{_question(question, choices)}\n\n'
            f'These {count} images are the most relevant views the drone has seen so far. If '
            'they are enough to answer confidently, think step by step about what they show, '
            'then end with a last line "Answer: <answer>"' +
            (' giving the letter of the option.' if choices else '.') +
            ' If they are not enough, reply with only the word Continue.')


def answer_prompt(question, choices, count):
    return (f'{_question(question, choices)}\n\n'
            f'These {count} images are the most relevant views the drone has seen. Think step '
            'by step about what they show, then end with a last line "Answer: <answer>"' +
            (' giving the letter of the option.' if choices else '.') +
            ' You must answer, even if you are unsure.')


def read_answer(reply):
    """The text of the reply's last `Answer:` line, or None."""
    found = _ANSWER.findall(reply)
    return found[-1] if found else None
```

```python
"""Image-text embedders for FAST-EQA: how relevant a view is to a target, and which room it is.

The paper uses CLIP for relevance and a SigLIP-aligned model to localise rooms; SigLIP does both
here by default, and anything with `image`, `text` and `match` replaces it (`embedder=
package.module:factory`). `match` is a score in [0, 1], not a cosine, because FAST-EQA mixes it
with a VLM's P(yes): SigLIP was trained with a sigmoid loss, so its own scale and bias turn a
cosine into a probability; CLIP was trained with a softmax over a batch and has no such pair, so
its cosine is mapped linearly from CLIP_RANGE, the cosines it typically gives a non-matching and
a matching caption.

SigLIP's text tower was trained on text padded to its full length: pad shorter, as transformers'
processor does by default, and its scores are wrong without any error. Both models load on first
use and import torch then; `sys.modules['triton'] = None` first, as drones.vlm.backend does,
because the simulator's EGL context makes triton segfault on import.
"""
import sys

import numpy as np

SIGLIP = 'google/siglip2-base-patch16-224'
CLIP = 'openai/clip-vit-base-patch32'
CLIP_RANGE = (0.15, 0.35)   # a cosine at the low end scores 0, at the high end 1
SIGLIP_TEXT_LENGTH = 64     # tokens SigLIP's text tower was trained on, padded
EXTRA = 'The FAST-EQA embedders need the vlm extra:  uv sync --extra sim --extra vlm'


def _unit(v):
    v = np.asarray(v, np.float32)
    return v / np.linalg.norm(v, axis=-1, keepdims=True)


def sigmoid_match(images, texts, scale, bias):
    """sigmoid(scale · cos + bias) for every image (rows) against every text (columns)."""
    return 1 / (1 + np.exp(-(scale * (np.asarray(images) @ np.asarray(texts).T) + bias)))


def affine_match(images, texts, low, high):
    """cos mapped from [low, high] to [0, 1], clipped."""
    cos = np.asarray(images) @ np.asarray(texts).T
    return np.clip((cos - low) / (high - low), 0.0, 1.0)


class _Transformers:
    """Loads `model` with transformers on first use and embeds through it."""

    def __init__(self, model, device=None):
        self.model, self.device = model, device
        self._net = self._processor = None

    def _load(self):
        sys.modules.setdefault('triton', None)
        try:
            import torch
            from transformers import AutoModel, AutoProcessor
        except ImportError as exc:
            raise SystemExit(f'{EXTRA}  ({exc})') from None
        self.device = self.device or ('cuda' if torch.cuda.is_available() else 'cpu')
        self._net = AutoModel.from_pretrained(self.model).to(self.device).eval()
        self._processor = AutoProcessor.from_pretrained(self.model)

    def _features(self, method, **inputs):
        import torch

        with torch.no_grad():
            out = getattr(self._net, method)(**{k: v.to(self.device) for k, v in inputs.items()})
        # transformers 5 may return an output object rather than the tensor.
        out = out if isinstance(out, torch.Tensor) else out.pooler_output
        return _unit(out[0].float().cpu().numpy())

    def image(self, image):
        if self._net is None:
            self._load()
        from PIL import Image

        inputs = self._processor(images=Image.fromarray(np.ascontiguousarray(image)),
                                 return_tensors='pt')
        return self._features('get_image_features', **inputs)

    def text(self, text):
        if self._net is None:
            self._load()
        return self._features('get_text_features', **self._text_inputs(text))

    def _text_inputs(self, text):
        return self._processor(text=[text], return_tensors='pt', padding=True)


class SiglipEmbedder(_Transformers):
    def __init__(self, model=SIGLIP, device=None):
        super().__init__(model, device)

    def _text_inputs(self, text):
        return self._processor(text=[text], return_tensors='pt', padding='max_length',
                               max_length=SIGLIP_TEXT_LENGTH)

    def match(self, images, texts):
        if self._net is None:
            self._load()
        scale = float(self._net.logit_scale.exp())
        bias = float(self._net.logit_bias)
        return sigmoid_match(images, texts, scale, bias)


class ClipEmbedder(_Transformers):
    def __init__(self, model=CLIP, device=None):
        super().__init__(model, device)

    def match(self, images, texts):
        return affine_match(images, texts, *CLIP_RANGE)
```

```python
"""Depth from the image alone, for FAST-EQA's map when no oracle is wanted.

What a real AI-deck would have to do: it has no depth sensor. Depth Anything V2's metric indoor
checkpoint gives metres directly, so the map needs no scale fit; a relative-depth model would,
and is not supported here. Its output is at the model's own resolution and is resized to the
frame. It is treated as the oracle's is, z-depth along the optical axis, which is what a
monocular network is trained to predict.

Anything with `estimate(image) -> (H, W) float32 m` replaces it (`depth=package.module:factory`).
"""
import sys

import numpy as np

DEPTH_ANYTHING = 'depth-anything/Depth-Anything-V2-Metric-Indoor-Small-hf'
EXTRA = 'Depth estimation needs the vlm extra:  uv sync --extra sim --extra vlm'


def resize(array, height, width):
    """Bilinear resize of a 2D `array` to (height, width), corners kept on corners."""
    a = np.asarray(array, np.float32)
    h, w = a.shape
    y = np.linspace(0, h - 1, height)
    x = np.linspace(0, w - 1, width)
    y0, x0 = np.floor(y).astype(int), np.floor(x).astype(int)
    y1, x1 = np.minimum(y0 + 1, h - 1), np.minimum(x0 + 1, w - 1)
    fy, fx = (y - y0)[:, None], (x - x0)[None, :]
    top = a[y0][:, x0] * (1 - fx) + a[y0][:, x1] * fx
    bottom = a[y1][:, x0] * (1 - fx) + a[y1][:, x1] * fx
    return (top * (1 - fy) + bottom * fy).astype(np.float32)


class DepthAnything:
    """`model` through transformers' depth-estimation pipeline, loaded on first use; `pipe` is
    a ready pipeline to use instead."""

    def __init__(self, model=DEPTH_ANYTHING, device=None, pipe=None):
        self.model, self.device, self._pipe = model, device, pipe

    def _load(self):
        sys.modules.setdefault('triton', None)
        try:
            import torch
            from transformers import pipeline
        except ImportError as exc:
            raise SystemExit(f'{EXTRA}  ({exc})') from None
        device = self.device or ('cuda' if torch.cuda.is_available() else 'cpu')
        return pipeline('depth-estimation', model=self.model, device=device)

    def estimate(self, image):
        if self._pipe is None:
            self._pipe = self._load()
        from PIL import Image

        out = self._pipe(Image.fromarray(np.ascontiguousarray(image)))['predicted_depth']
        if hasattr(out, 'cpu'):                 # a torch tensor
            out = out.float().cpu().numpy()
        out = np.asarray(out, np.float32).reshape(np.asarray(out).shape[-2:])
        return resize(out, image.shape[0], image.shape[1])
```

```python
Room A (blue walls) is x in [-2, 2], room B (red walls, the kitchen) x in [2, 6], both 4 m wide in
y and 2.5 m high. The wall between them, at x = 2, has a door 1 m wide at |y| < 0.5. The view
casts rays against those walls, the floor and the ceiling, and returns z-depth through the lens.

HEIGHT = 2.5
BLUE, RED = (40, 40, 220), (220, 40, 40)
# (x0, y0, x1, y1, colour): the colour a wall shows from inside the room it bounds.
WALLS = [(-2, -2, -2, 2, BLUE), (-2, -2, 2, -2, BLUE), (-2, 2, 2, 2, BLUE),
         (2, -2, 2, -0.5, BLUE), (2, 0.5, 2, 2, BLUE),
         (2, -2, 6, -2, RED), (2, 2, 6, 2, RED), (6, -2, 6, 2, RED)]


class House:
    """A SceneView stand-in: images and z-depth of the two-room house through `lens`."""

    def __init__(self, width=48, height=36):
        self.lens = type('Lens', (), {'intrinsics': Intrinsics.from_fov(width, height, 1.4)})()
        self.mount = Mount()
        self.scene = type('Scene', (), {'origin': np.zeros(3)})()

    def render_matrix(self, pos, rotation, depth=False):
        k = self.lens.intrinsics
        v, u = np.mgrid[0:k.height, 0:k.width]
        x, y = (u - k.cx) / k.fx, (v - k.cy) / k.fy
        rays = np.stack([np.ones_like(x), -x, -y], -1).reshape(-1, 3) @ rotation.T
        eye = np.asarray(pos, float)
        t = np.full(len(rays), np.inf)
        colour = np.zeros((len(rays), 3))
        for z, shade in ((0.0, 90), (HEIGHT, 160)):         # floor, ceiling
            with np.errstate(divide='ignore', invalid='ignore'):
                s = (z - eye[2]) / rays[:, 2]
            ok = (s > 0) & (s < t)
            t[ok], colour[ok] = s[ok], shade
        for x0, y0, x1, y1, wall in WALLS:
            d = np.array([x1 - x0, y1 - y0], float)
            normal = np.array([-d[1], d[0]])
            with np.errstate(divide='ignore', invalid='ignore'):
                s = ((np.array([x0, y0]) - eye[:2]) @ normal) / (rays[:, :2] @ normal)
            hit = eye[:2] + rays[:, :2] * s[:, None]
            along = ((hit - [x0, y0]) @ d) / (d @ d)
            zs = eye[2] + rays[:, 2] * s
            ok = (s > 0) & (s < t) & (along >= 0) & (along <= 1) & (zs > 0) & (zs < HEIGHT)
            t[ok], colour[ok] = s[ok], wall
        image = colour.reshape(k.height, k.width, 3).astype(np.uint8)
        if not depth:
            return image
        # The rays' forward component is 1 in camera axes, so t is z-depth.
        return image, t.reshape(k.height, k.width).astype(np.float32)


def red_share(image):
    image = np.asarray(image, float)
    return float(((image[..., 0] > 150) & (image[..., 2] < 100)).mean())


class Reasoner:
    """Parses to a red mug in the kitchen; answers B once any memory image is mostly red."""

    def __init__(self, plan='{"targets": ["red mug"], "rooms": ["kitchen"]}'):
        self.plan, self.asked = plan, []

    def generate(self, prompt, image=None):
        self.asked.append(prompt)
        if '"targets"' in prompt:
            return self.plan
        images = image if isinstance(image, list) else [image]
        if any(red_share(i) > 0.3 for i in images):
            return 'The walls are red.\nAnswer: B'
        return 'Continue' if 'Continue' in prompt else 'I cannot tell.\nAnswer: A'


class Scorer:
    def __init__(self):
        self.calls = 0

    def yes_probability(self, prompt, image=None):
        self.calls += 1
        return red_share(image)

    def generate(self, prompt, image=None):
        raise AssertionError('a scorer with yes_probability is not asked for words')


class Embedder:
    """3-d 'embeddings': an image is its mean colour; red things and the kitchen are red."""

    def image(self, image):
        v = np.asarray(image, float).reshape(-1, 3).mean(axis=0) + 1e-6
        return v / np.linalg.norm(v)

    def text(self, text):
        v = np.array([1.0, 0.05, 0.05]) if ('red' in text or 'kitchen' in text) else \
            np.array([0.05, 0.05, 1.0])
        return v / np.linalg.norm(v)

    def match(self, images, texts):
        return np.clip(np.asarray(images) @ np.asarray(texts).T, 0, 1)

def run(agent, budget=12, view=None):

    return seen
```

```python
"""FAST-EQA (arXiv 2602.15813) as an agent: drones-benchmark run --agent drones.fasteqa:make

    uv run --extra sim --extra vlm drones-benchmark run --benchmark hm-eqa \\
        --agent drones.fasteqa:make --agent-arg reasoner=claude-code \\
        --agent-arg scorer=openai --agent-arg scorer_model=Qwen/... --agent-arg scorer_url=...

What the paper does, and how it is done here. The question is parsed once, by the `reasoner`,
into targets and the rooms they are likely in. Every frame's depth is fused into a floor plan
(drones.fasteqa.mapping). A decision is one Explore-EQA step: the first view of each, and the
eight views of a panorama, are scored per target as λ·match(embedder) + (1-λ)·P(yes) from the
`scorer`, and the k best per target kept (drones.fasteqa.memory). In a room the question points
to, not yet panned, the decision is a panorama (the paper's local relevance); otherwise the
drone flies up to `reach` along an A* path to the best doorway or frontier cluster (its global
relevance), scored by size, unknown space around it, and how much the views towards it look like
the rooms it wants. When the memory has changed, the reasoner sees it and either answers, after
reasoning step by step, or says to continue. When the budget runs out, `conclude` makes it
answer.

Four parts are swappable by --agent-arg: `reasoner` and `scorer` (claude-code, openai,
transformers, or package.module:factory for anything with generate), `embedder` (siglip, clip,
or a factory for anything with image, text and match) and `depth` (oracle, MuJoCo's depth
buffer; depth-anything, estimated from the frame; or a factory for anything with estimate). A
scorer with `yes_probability` gives a probability; one without (Claude) is asked for a word,
read as 1 or 0, at a model call per scored view.

DEVIATIONS lists where this departs from the paper; drones-benchmark puts it in a run's report.
One decision flies `reach` = 3 m, the paper's step, over `chunk_size` frames, so films are smooth
and the benchmark's budget of decisions is Explore-EQA's.
"""

def _angle(a):
    return (a + math.pi) % (2 * math.pi) - math.pi


def _load(spec):
    """`package.module:factory`, called with no arguments."""
    module, sep, attr = spec.partition(':')
    if not sep:
        return None
    return getattr(importlib.import_module(module), attr)()


def _backend(role, kind, model, url, max_new_tokens, system=None):
    if not isinstance(kind, str):
        return kind
    if kind == 'claude-code':
        return ClaudeCodeBackend(model or CLAUDE_MODEL,
                                 **({'system': system} if system else {}))
    if kind == 'openai':
        if not model:
            raise ValueError(f'{role}=openai needs the served model, as {role}_model=NAME')
        return OpenAIBackend(model, url, max_new_tokens, system=system)
    if kind == 'transformers':
        return TransformersBackend(model or DEFAULT_MODEL, max_new_tokens)
    loaded = _load(kind)
    if loaded is None:
        raise ValueError(f'{role} is claude-code, openai, transformers or package.module:factory,'
                         f' not {kind!r}')
    return loaded

class FastEQAAgent:
    chunk_size = CHUNK
    reach = REACH
    deviations = DEVIATIONS

    def __init__(self, reasoner, scorer, embedder, depth_model=None, lambda_=LAMBDA, k=K,
                 start_altitude=1.0):
        self.reasoner, self.scorer, self.embedder = reasoner, scorer, embedder
        self.depth_model = depth_model
        self.depth = depth_model is None        # the oracle: agents.episode renders it
        self.camera = None                      # set by agents.episode
        self.lam, self.k = float(lambda_), int(k)
        self.start_altitude = float(start_altitude)
        self.calls, self.answer, self.error = [], None, None
        self.stats = {}
        self.targets, self.rooms = [], []
        self.mode, self.room = 'start', None

    # -- the agent protocol --------------------------------------------------------------

    def reset(self, question, pose):
        self.question = getattr(question, 'text', None)
        self.choices = tuple(getattr(question, 'choices', ()) or ())
        self.floor = float(pose.pos[2]) - self.start_altitude
        self.map = mapping.OccupancyMap(pose.pos[:2], self.floor)
        self.calls, self.answer, self.error = [], None, None
        self.stats = {'parse': 0, 'retry': 0, 'score': 0, 'stop': 0, 'answer': 0}
        self.plan, self._score_next = [], False
        self.views = []                         # (pos, yaw, image vector) of every scored view
        self.mode, self.room, self.target = 'start', None, None
        self.panned, self.away = False, 0
        self.unreachable = set()
        self._step, self._pose = 0, pose
        self.targets, self.rooms = self._parse() if self.question else ([], [])
        self.memory = Memory(self.targets, self.k)
        names = list(prompts.ROOMS) + [r for r in self.rooms if r not in prompts.ROOMS]
        self.room_names = names
        self.room_vectors = np.array([self.embedder.text(f'a photo of a {r}') for r in names])
        self.target_vectors = np.array([self.embedder.text(f'a photo of a {t}')
                                        for t in self.targets]) if self.targets else None

    def act(self, observation):
        self._step, self._pose = observation.step, observation.pose
        self._fuse(observation)
        if self._score_next:
            self._score(observation)
        if not self.plan:
            if not self._decide(observation):
                return None
        pose, self._score_next = self.plan.pop(0)
        return pose

    def conclude(self, observation):
        """The answer from memory, after a last look at `observation`, once the budget is out."""
        self._step, self._pose = observation.step, observation.pose
        self._fuse(observation)
        self._score(observation)
        views = self.memory.views() or [self._view(observation)]
        reply = self._ask('answer', prompts.answer_prompt(self.question, self.choices,
                                                          len(views)), views)
        self.answer = prompts.read_answer(reply) or reply.strip()
        self.mode = 'answered'
        return self.answer

    @property
    def caption(self):
        lines = [f'{self.mode}   room: {self.room or "-"}   targets: '
                 + (', '.join(self.targets) or '-')]
        best = self.memory.best() if self.targets else {}
        if best:
            lines.append('memory: ' + '   '.join(f'{t} {s:.2f}' for t, s in best.items()))
        if self.answer is not None:
            lines.append(f'answer: {self.answer}')
        return lines

    # -- one decision ------------------------------------------------------------------

    def _decide(self, observation):
        """Plan the next CHUNK poses; False when the agent has answered and stops."""
        self._score(observation)
        self._tag_room(observation)
        if self.targets and self.memory.changed:
            self.memory.changed = False
            views = self.memory.views()
            reply = self._ask('stop', prompts.stop_prompt(self.question, self.choices,
                                                          len(views)), views)
            answer = prompts.read_answer(reply)
            if answer is not None:
                self.answer, self.mode = answer, 'answered'
                return False
        pose = observation.pose
        if self.mode == 'start' or (self.room in self.rooms and not self.panned):
            self.mode, self.panned, self.away = 'panorama', True, 0
            self.plan = self._panorama(pose)
            return True
        path = self._frontier_path(pose)
        if path is None:
            self.mode = 'turn'
            self.plan = [(Pose(pose.pos, pose.yaw + TURN * i / CHUNK), False)
                         for i in range(1, CHUNK + 1)]
        else:
            self.mode = 'explore'
            self.plan = self._fly(pose, path)
        return True

    def _panorama(self, pose):
        """CHUNK poses turning once round; the frame at each PANORAMA-th of the turn is
        scored, the last (the start view again) left to the next decision."""
        every = CHUNK // PANORAMA
        return [(Pose(pose.pos, pose.yaw + 2 * math.pi * i / CHUNK),
                 i % every == 0 and i < CHUNK) for i in range(1, CHUNK + 1)]

    def _fly(self, pose, path):
        """CHUNK poses along `path` (points from here), up to REACH, facing along it."""
        points = np.vstack([pose.pos[:2], path])
        seg = np.linalg.norm(np.diff(points, axis=0), axis=1)
        along = np.concatenate([[0.0], np.cumsum(seg)])
        total = min(REACH, along[-1])
        heading = pose.yaw
        plan = []
        for i in range(1, CHUNK + 1):
            s = total * i / CHUNK
            j = min(int(np.searchsorted(along, s, side='right')) - 1, len(seg) - 1)
            f = 0.0 if seg[j] == 0 else (s - along[j]) / seg[j]
            xy = points[j] + f * (points[j + 1] - points[j])
            d = points[j + 1] - points[j]
            if np.linalg.norm(d) > 1e-9:
                heading = math.atan2(d[1], d[0])
            yaw = pose.yaw + _angle(heading - pose.yaw) * min(1.0, 2 * i / CHUNK)
            plan.append((Pose(np.array([xy[0], xy[1], pose.pos[2]]), yaw), False))
        return plan

    def _frontier_path(self, pose):
        """Points to the best reachable doorway or frontier cluster, or None."""
        m = self.map
        radius = max(1, int(round(mapping.EPS / m.cell)))
        groups = [(c, True) for c in mapping.clusters(m.doorways(), radius, mapping.MIN_POINTS)]
        groups += [(c, False) for c in mapping.clusters(m.frontiers(), radius,
                                                        mapping.MIN_POINTS)]
        here = m.index(pose.pos[:2])[0]
        passable = m.traversable()
        largest = max((len(c) for c, _ in groups), default=1)
        scored = []
        for cells, door in groups:
            centre = m.centre(cells).mean(axis=0)
            goal_cells = cells[passable[cells[:, 0], cells[:, 1]]]
            if not len(goal_cells):
                continue
            goal = goal_cells[np.argmin(np.linalg.norm(m.centre(goal_cells) - centre, axis=1))]
            if tuple(goal) in self.unreachable:
                continue
            distance = float(np.linalg.norm(centre - pose.pos[:2]))
            if distance < ARRIVED:
                continue
            score = (WEIGHTS['size'] * len(cells) / largest
                     + WEIGHTS['unknown'] * m.unknown_near(tuple(goal), 1.0)
                     + WEIGHTS['room'] * self._room_towards(centre)
                     + WEIGHTS['door'] * door - WEIGHTS['distance'] * distance)
            scored.append((score, tuple(goal)))
        for _, goal in sorted(scored, reverse=True):
            cells = mapping.astar(passable, tuple(here), goal, free=m.grid == mapping.FREE)
            if cells is not None:
                self.target = goal
                return m.centre(np.array(cells[1:] or cells))
            self.unreachable.add(goal)
        return None

    def _room_towards(self, point):
        """How much the scored views looking towards `point` look like the wanted rooms."""
        if not self.rooms or not self.views:
            return 0.0
        hfov = self._hfov()
        wanted = [self.room_names.index(r) for r in self.rooms]
        best = 0.0
        for pos, yaw, vector in self.views:
            bearing = math.atan2(point[1] - pos[1], point[0] - pos[0])
            if abs(_angle(bearing - yaw)) <= hfov / 2:
                scores = self.embedder.match(vector[None], self.room_vectors[wanted])
                best = max(best, float(np.max(scores)))
        return best

    def _hfov(self):
        k = self.camera.intrinsics if self.camera is not None else None
        return 2 * math.atan(k.width / 2 / k.fx) if k is not None else math.pi / 2

    # -- per view ----------------------------------------------------------------------

    def _fuse(self, observation):
        if self.camera is None:
            return
        depth = observation.depth
        if depth is None:
            if self.depth_model is None:
                return
            depth = self.depth_model.estimate(observation.image)
        pose = observation.pose
        eye, rotation = self.camera.mount.camera_pose(pose.pos, euler_to_matrix(
            pose.yaw, pose.pitch, pose.roll))
        hits, misses = mapping.backproject(depth, self.camera.intrinsics, eye, rotation,
                                           stride=STRIDE)
        self.map.fuse(eye, hits, misses)

    def _view(self, observation):
        p = observation.pose
        return View(observation.image, np.asarray(p.pos, float), float(p.yaw), observation.step)

    def _score(self, observation):
        """Score the view for each target and offer it to memory; remember where it looked."""
        vector = self.embedder.image(observation.image)
        p = observation.pose
        self.views.append((np.asarray(p.pos, float), float(p.yaw), vector))
        if not self.targets:
            return
        embed = self.embedder.match(vector[None], self.target_vectors)[0]
        relevance = self._relevance(observation.image)
        scores = {t: self.lam * float(e) + (1 - self.lam) * relevance
                  for t, e in zip(self.targets, embed, strict=True)}
        self.memory.offer(self._view(observation), scores)

    def _relevance(self, image):
        prompt = prompts.relevance_prompt(self.question)
        started = time.perf_counter()
        self.stats['score'] += 1
        if hasattr(self.scorer, 'yes_probability'):
            p = self.scorer.yes_probability(prompt, image)
            if p is not None:
                self._record('score', prompt, f'{p:.4f}', image, started, self.scorer)
                return float(p)
        reply = self.scorer.generate(prompt, image)
        self._record('score', prompt, reply, image, started, self.scorer)
        return prompts.read_yes(reply)

    def _tag_room(self, observation):
        vector = self.views[-1][2]
        scores = self.embedder.match(vector[None], self.room_vectors)[0]
        room = self.room_names[int(np.argmax(scores))]
        if self.panned and room != self.room:
            self.away += 1
            if self.away >= LEFT_ROOM:
                self.panned, self.away = False, 0
        elif room == self.room:
            self.away = 0
        self.room = room

    # -- the reasoner --------------------------------------------------------------------

    def _parse(self):
        prompt = prompts.parse_prompt(self.question, self.choices)
        for attempt in range(2):
            self.stats['parse'] += 1
            if attempt:
                self.stats['retry'] += 1
            started = time.perf_counter()
            reply = self.reasoner.generate(prompt, None)
            self._record('parse', prompt, reply, None, started, self.reasoner)
            try:
                return prompts.parse_plan(reply)
            except ValueError as exc:
                self.error = None
                self.calls[-1]['error'] = str(exc)
        return [self.question], []

    def _ask(self, role, prompt, views):
        self.stats[role] += 1
        started = time.perf_counter()
        reply = self.reasoner.generate(prompt, [v.image for v in views])
        self._record(role, prompt, reply, views[0].image, started, self.reasoner,
                     memory_steps=[v.step for v in views])
        return reply

    def _record(self, role, prompt, reply, image, started, backend, **extra):
        self.calls.append({
            'role': role, 'step': self._step, 'prompt': prompt, 'reply': reply,
            'image': image, 'seconds': time.perf_counter() - started,
            'pos': [float(x) for x in self._pose.pos], 'yaw': float(self._pose.yaw),
            'model': getattr(backend, 'resolved_model', None) or getattr(backend, 'model', None),
            'system': getattr(backend, 'system', None), **extra})


def make(reasoner='claude-code', reasoner_model=None, reasoner_url=OPENAI_URL,
         scorer='transformers', scorer_model=None, scorer_url=OPENAI_URL,
         embedder='siglip', embedder_model=None, depth='oracle', depth_model=None,
         lambda_=LAMBDA, k=K, start_altitude=1.0):
    """The agent factory, for --agent drones.fasteqa:make. Each part is a built-in name, a
    package.module:factory, or (in tests) the object itself."""
    return FastEQAAgent(
        _backend('reasoner', reasoner, reasoner_model, reasoner_url, REASONER_TOKENS,
                 prompts.REASONER_SYSTEM),
        _backend('scorer', scorer, scorer_model, scorer_url, 4),
        _embedder(embedder, embedder_model),
        _depth(depth, depth_model), lambda_, k, start_altitude)
```
